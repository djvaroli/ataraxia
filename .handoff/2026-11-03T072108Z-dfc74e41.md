## Decisions

Prioritize security, working personal flows, composable modules, dependency injection,
narrow interfaces/protocols, precise types, reusable tools, and cheap deterministic
unit tests. Apply justified in-scope review fixes without per-finding permission;
file useful deferrals as issues with evidence and triggers. No issues were needed
from this session's reviews. Dedicated screen-reader polish and speculative
production infrastructure are outside automatic remediation.

The owner retains merge, deployment, cloud provisioning, and provider-spending
decisions. Firebase/GCP must be dedicated to Ataraxia. Live identity configuration,
provider/model/budget, and host/domain remain unset; fakes permit implementation.
Redis backup/restore remains required before regular personal use, not fixture work.
