# Ataraxia handoff

## Objective

A private learning app for the owner: one Claude-written 10–15 minute lesson a day
across 11 subjects, with save, rating, finish, follow-ups ("Go deeper"), a Library,
Progress, and a complete activity record that later sessions can use for recaps,
tuning, and quizzes. It must later run on a VM reachable from the owner's phone with
Firebase sign-in, without exposing data or the machine. Habit tracking is deferred.

## Decisions

- Lessons before habits; SQLite instead of Redis; the Claude CLI runs only in the
  worker with tools, MCP, and settings off, an explicit environment without API keys,
  a pinned and checksummed binary, and a hard timeout.
- Auth: Firebase ID tokens plus `ATARAXIA_OWNER_UID`; `local` mode only for
  development, refused for non-loopback Host, proxy or Tailscale headers, and
  cross-site requests. The VM is to be reachable only over Tailscale.
- The owner authorized agents (24 November) to commit and merge reviewed PRs with
  passing checks; deploying, provisioning, and paid provider use still need the owner.
  Stacks merge through `PUT /pulls/{top}/merge-async`. Branches use `claude/`.
- An interactive Claude login lasts about a month; for the VM prefer
  `claude setup-token` (one year) in `.env` as `CLAUDE_CODE_OAUTH_TOKEN`.
